Sumber metodologi

  • OWASP Web Security Testing Guide (WSTG) — kerangka fase pengujian: information gathering, config, auth, session, input validation, business logic.
  • OWASP Top 10 — kategori risiko aplikasi web paling umum.
  • OWASP API Security Top 10 (2023) — BOLA, broken auth, BOPLA, resource consumption, SSRF pada API, dsb.
  • PortSwigger Web Security Academy — urutan lab server-side → client-side, termasuk access control, cache, request smuggling.
  • Jason Haddix — The Bug Hunter's Methodology (TBHM), talk recon & application analysis (DEF CON / Red Team Village).
  • HackerOne — Hacker101 — silabus dasar web hacking untuk pemula bug bounty.
